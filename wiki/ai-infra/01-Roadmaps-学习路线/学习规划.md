
跨越从高层 Python 到底层 C++/CUDA 。在 Windows 环境下进行开发时，深度依赖 **WSL2** 省去极多环境配置的麻烦
### **Phase 1: CUDA 筑基与算子入门 (Weeks 1-3)**

关联阅读：可结合 [推理加速与算子优化路线](LLM%20%E6%8E%A8%E7%90%86%E5%8A%A0%E9%80%9F%E4%B8%8E%E7%AE%97%E5%AD%90%E4%BC%98%E5%8C%96%E5%AD%A6%E4%B9%A0%E8%B7%AF%E7%BA%BF.md) 理解；学习规划是推理加速路线的时间化执行版本。


- **目标**：掌握 CUDA C++ 语法，理解 GPU 内存模型。
- **行动**：
    1. 阅读《CUDA 编程：基础与实践》，跟着敲击基础代码。
    2. 精读 PMPP 中的核心章节：Global Memory 优化、Shared Memory 与 Tiling（分块操作）、Warp 执行机制。
    3. 实战：在 LeetGPU 上刷题，完成 **Vector Add**, **Matrix Multiply** (Naïve -> Shared Memory 优化版), **Reduction**等基础算子。 Claude 在这个阶段可以作为极好的 CUDA C++ 语法导师，帮你解析晦涩的报错信息。
### **Phase 2: LLM 推理与量化理论 (Weeks 4-6)**

- **目标**：理解 LLM Inference 为什么慢，以及量化是如何加速的。
- **行动**：
    1. 学习 Transformer 推理的两大阶段：Prefill（计算密集型）和 Decode（访存密集型）。
    2. 精读 GPTQ、AWQ 和 SmoothQuant 论文。重点关注它们的核心 insight：为什么要这么做？解决了什么硬件瓶颈？
    3. **实战**：克隆 AWQ 或 SmoothQuant 的开源代码，尝试在一个开源小模型（如 Llama-3-8B）上跑通量化脚本，对比量化前后的显存占用和生成速度。

### **Phase 3: 前沿算法与架构拆解 (Weeks 7-8)**

- **目标**：理解系统级和算法级的提速方案。
- **行动**：
    1. 阅读 MEDUSA 论文，理解 Speculative Decoding 的数学原理和树状注意力机制（Tree Attention）。
    2. 了解目前主流的显存管理技术，如 PagedAttention（vLLM 的核心）。
        
#### **Phase 4: 挑战工业级框架 TensorRT-LLM (Weeks 9-12)**

- **目标**：具备将大模型转化为高效推理引擎并在生产环境部署的能力。
- **行动**：
    1. 通读 TensorRT-LLM 的官方文档和 Examples 目录。
    2. 理解它的大致编译工作流：HuggingFace Checkpoint -> Build Engine -> Runtime Inference。
    3. **实战**：尝试使用 TensorRT-LLM 编译并运行一个应用了 SmoothQuant 或 AWQ 的模型引擎。
